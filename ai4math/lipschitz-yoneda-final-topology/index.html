Final topologies of Lipschitz Yoneda-continuous maps in Lean 4

Mechanized proof · headline theorem formalized

This note reports a Lean 4 proof of the main theorem in a manuscript addressing Jean Goubault-Larrecq's public problem on the topology of Lipschitz Yoneda-continuous function spaces. The formal development contains the argument based on a finitely branching tree of cone functions, the rounded-ideal completion, and the nonexpansive Yoneda-continuous retract used to pass from the algebraic case to every continuous Yoneda-complete quasi-metric space.

Formalized main theorem. If X is a continuous Yoneda-complete quasi-metric space, then the topology on L∞(X) is the final topology determined by its fixed Lipschitz layers. In Lean this is QuasiMetric.IsContinuous.propertyD, an actual theorem with a proof term and no project-specific axiom. The manuscript's separate converse characterization for ordinary metric spaces remains outside the present Lean boundary.

Goubault-Larrecq's open problem

In the original problem post, Goubault-Larrecq asks whether, for a complete metric space, every subset of L∞(X) that is open on each fixed layer must already be open globally. Equivalently, is L∞(X) the topological colimit of the inclusions of the spaces Lα(X)?

The same page presents the continuous Yoneda-complete setting as the more general question. The problem was posted on February 23, 2017 and is still shown on the open-problems index with the label “really tough.” The manuscript proves the final-topology property for continuous Yoneda-complete quasi-metric spaces.

The formalized mathematical route

  1. Reduce the arbitrary positive Lipschitz constants to a cofinal sequence of integer layers.
  2. Show that a set open on every layer is upward closed in the pointwise order.
  3. In the algebraic case, recursively approximate functions by finite maxima of cones and organize them into a finitely branching tree.
  4. Compactify the finite and infinite branches, extract compact saturated test sets, and construct a global compact-open neighborhood.
  5. Construct the rounded-ideal formal-ball completion, prove that it is algebraic and Yoneda-complete, and pass back through an explicitly verified nonexpansive Yoneda- and d-Scott-continuous retract.

The proof uses results about function-space topologies from Complete Quasi-Metrics for Hyperspaces, Continuous Valuations, and Previsions and the formal-ball retract theory developed in A Few Notes on Formal Balls.

Boundary after the main theorem

The generalized main implication is now checked, but the archive is not a formalization of every theorem in the manuscript. In particular, it does not yet package the standard bridge from ordinary complete metric spaces to the continuous Yoneda-complete hypotheses, nor the converse construction showing failure of the final-topology property for an incomplete metric space.
