Why use AI for literature search? A coherence-space case study

Research-audit case study · revised mathematical note · Lean 4 formalization

All content in this section is AI-generated. AI may make mistakes; please verify important information carefully.

This post records a useful correction. Starting from a 2015 coordinate universal coherence space, we proved that it is not ultrahomogeneous and initially treated an arithmetic Rado coherence space as a new homogeneous replacement. An AI-assisted source audit found the exact binary-digit construction in Rado's 1964 paper and a 2002 paper explicitly constructing universal homogeneous objects in coherence spaces and qualitative domains. The mathematics survived; the novelty claim did not.

Research lesson. AI is useful here not as an authority on novelty, but as a search and comparison tool. It can connect terminology used in different communities, locate older sources, compare definitions formula by formula, and force a proposed contribution to be stated more narrowly. The final judgement must still be based on verified primary literature.

The initial mathematical question

Hui Kou and Haoran Zhao constructed a universal coherence space in 2015 from the compact elements of Tω. In a finite-coordinate presentation, its events are finite partial functions from the natural numbers to {0,1}; two distinct events are coherent exactly when they assign different values at a common coordinate. We write this space as Cω.

The empty partial function is coherent only with itself. Every nonempty partial function has a distinct coherent neighbour, obtained by reversing one bit on a coordinate in its domain. The empty function is therefore uniquely definable and fixed by every automorphism. Yet every one-event induced subspace is isomorphic to every other one. The isomorphism sending the empty function to a nonempty function cannot extend to an automorphism, so Cω is not ultrahomogeneous.

The supplied 2015 source does not analyse ultrahomogeneity, but it also does not explicitly state this as an open problem. That distinction matters: the argument determines an additional property of the particular construction, but should not be advertised as solving a stated public question without a source that actually asks it.

The tempting novelty claim

A natural comparison object is obtained on the natural numbers by declaring distinct m < n coherent when the m-th binary digit of n is 1, then adding the reflexive loops required by the coherence-space convention. The definition is direct rather than recursive. A finite set of desired adjacencies can be encoded into the binary digits of one fresh natural number, giving the extension property and hence universality and ultrahomogeneity.

Because the 2015 coordinate paper did not use this construction, it was tempting to describe it as a new explicit homogeneous replacement. That conclusion was incorrect.

What the AI-assisted search found

  1. Rado's 1964 paper already defines the graph directly on the natural numbers using exactly this binary-digit rule. The graph is explicit; only the proof that an arbitrary countable graph embeds into it proceeds inductively.
  2. Boldi, Cardone, and Droste (2002) explicitly study universal homogeneous graph-like structures and construct such objects in the categories of coherence spaces and qualitative domains.
  3. Adding a loop at each vertex translates a simple graph into the reflexive coherence-space convention. It does not by itself constitute a new homogeneous construction.

Once these sources were checked, the phrase “we give an explicit homogeneous replacement” had to be removed from the mathematical note. The Rado object is now presented as classical background and as a comparison object for Cω.

What remains after the correction

The concrete proof that this particular Cω is not ultrahomogeneous remains valid. The revised note compares its exceptional empty event with the finite extension property of the classical Rado graph and explains the induced section–retraction maps on state domains. A more comprehensive literature review would still be required before asserting that the non-ultrahomogeneity observation itself has never appeared elsewhere.

The Lean development also remains useful. It machine-checks the coordinate construction, its exceptional empty event, the non-ultrahomogeneity proof, the classical Rado extension argument, and the set-level retraction and Karoubi equations. Formalizing a classical theorem is valuable verification work, but it does not make that theorem mathematically new.

Why use AI in this part of research?

  1. Terminology matching. The same object may appear as a random graph, Rado graph, universal homogeneous graph, reflexive coherence graph, or a qualitative-domain carrier.
  2. Definition-level comparison. Comparing the binary formula in the draft with the formula in the 1964 source revealed exact identity, not merely a vague resemblance.
  3. Adversarial claim checking. Asking whether a result is really new is often more valuable than asking for a polished proof of it.
  4. Traceable correction. The source audit now records which claims are classical, which statement concerns the 2015 coordinate object, and which parts are only formalization or exposition.

AI can still hallucinate references, miss papers, or confuse nearby notions. The safe workflow is therefore: use AI to broaden and organize the search, open the primary sources, compare the exact definitions and hypotheses, and then revise the novelty statement conservatively.

Verification and trust boundary

The Lean entrypoint and axiom-audit targets compile with Lean v4.30.0-rc2 and the repository's pinned Mathlib dependency. The source contains no sorry, admit, or custom axiom declaration. The main declarations depend only on the standard Lean/Mathlib principles reported by #print axioms.

The complete categorical semantics of propositional linear logic is not rebuilt in Lean. The appendices about linear traces, formula interpretations, universal retracts, and the ideal-completion description are mathematical exposition. Neither a successful Lean build nor an AI literature search certifies global novelty.
